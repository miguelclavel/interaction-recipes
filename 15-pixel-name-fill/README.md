# A name that fills in with colour, pixel by pixel

<img src="demo.gif" width="720" alt="A name that fills in with colour, pixel by pixel: a screen recording">

My name fills in with color, pixel by pixel, like an old dot-matrix printer catching up to itself.

Each letter is drawn onto a canvas using the page's own font, then covered with a grid of small squares. As the text scrolls into view, the squares clear from the bottom up, using a dithered edge instead of a hard line, so it looks like static resolving into a picture instead of a wipe.

Here's a prompt that gets you the same idea:

## The prompt

Copy it as it is and paste it into Claude, or any AI coding tool.

```text
Render a piece of heading text onto a canvas using the page's real font. Overlay it with a grid of small pixel-sized squares in a short color palette. As the text scrolls into view, reveal the underlying letters from the bottom up by clearing squares progressively, but instead of a hard clean edge, use a dithering pattern so the boundary between revealed and hidden looks textured, like a screen door, not a straight wipe.
```
